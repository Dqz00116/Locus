Locus uses the Java renderer, key encoder, terminal emulator, and text selection
resources. It replaces the local subprocess session with a remote byte-stream
session, uses its own InputConnection, and limits clipboard actions to Android
user input. The Termux application and local subprocess JNI code are excluded.

The character-width tables in Termux's WcWidth are derived from wcwidth
at commit 1b9b6585b0080ea5cb88dc9815796505724793fe under the MIT license.
https://github.com/jquast/wcwidth/tree/1b9b6585b0080ea5cb88dc9815796505724793fe
See wcwidth-mit.txt.
